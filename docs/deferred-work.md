# Deferred work

These are possible extensions, not requirements for the frozen case study.

- Semantic model-assisted grading could assess claim entailment; it is not part
  of this release.
- Failure taxonomy labels could be written into future-run traces.
- Dataset consistency fixes would require a new report version because the
  current held-out evidence is frozen.
- More cases or a new corpus would require a new experimental design.
- Cost accounting, production serving, and security work are outside this
  controlled evaluation case study.

Current conclusions remain limited to deterministic, trace-derived evidence:
evidence-span recall, MRR, precision, document recall, citation resolution,
abstention behaviour, failure analysis, and regression tests.
